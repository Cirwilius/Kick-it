# KICK IT - Physics Arcade Soccer

Physics first: Every bounce, slip and rebound matters. Master the chaos.

Control agile players, master the ball, and become tournament champion.

### MODES
- **1 PLAYER:** vs CPU - EASY, MEDIUM, HARD, INSANE
- **2 PLAYERS LOCAL:** Classic couch vs
- **2v2 TEAMS:** Play with a bot teammate, customize rival bots
- **ONLINE MULTIPLAYER:** Host a room, Join by ID or Quick Play
- **TOURNAMENT:** 4 / 8 / 16 players bracket - Quarterfinals, Semifinals, Final
- **TRAINING MODE:** Practice without pressure

### FEATURES
- **Achievements & Stats** - First Whistle, Net Breaker, Champion, Steel Wall, Goal Machine and more
- **Multi-language** - EN, ES, FR, DE, PT, IT, JA, ZH
- **Customization** - Player names, bot teammate and rivals
- **Controller support & persistent settings**

A football arcade game inspired by classic physics and head-to-head competition.
Every touch counts, every slip is an opportunity.
